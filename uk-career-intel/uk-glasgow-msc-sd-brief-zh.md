## 二、簽證（國際生｜信心：高）

### Graduate visa
- 2026-12-31（含）前申請 → **2 年**
- 2027-01-01 起申請 → **18 個月**（PhD 仍 3 年）
- 須在英國境內；學校已通報完成學業；申請費 £937；IHS 約 £1,035／年
- **不可延長**；之後多轉 Skilled Worker

**對 2026 年 9 月入學的影響：** 一年制約 2027 年中／秋畢業，多半會落在 **18 個月** 時程——這是規劃換工簽證的硬約束。

來源：https://www.gov.uk/graduate-visa

### Skilled Worker（軟體｜SOC 2134）
- 一般門檻 **£41,700** 或職缺 going rate，取較高
- Programmers / software development professionals going rate：**£54,700／年**（標準）
- New entrant（含近期 Graduate 等條件）：可至 going rate 的 **70%** → 約 **£38,300**（另須滿足 £33,400 等條件）
- MAC（2026-01）指出廣告薪資中位數常低於 £54,700，許多開發職 **標準贊助不易**——新人折扣／Graduate Route 過渡很關鍵

來源：https://www.gov.uk/skilled-worker-visa/your-job 與 Appendix Skilled Occupations

## 四、對格大轉型碩士的結論

1. **簽證時鐘**是國際生主約束：Graduate Route 先累積經驗，同時瞄準可贊助雇主（新人門檻約 £38.3k，長期標準約 £54.7k）。
2. **作品集／專題**（團隊＋60 學分個人專案）決定競爭力，勝過「Conversion」標籤本身；本碩**無**保證產業實習，實習需另覓。
3. 選城取捨：要量與贊助 → London；蘇格蘭薪資與生態 → Edinburgh；成本＋在地網絡 → Glasgow；折衷成長城 → Manchester；資安／航太 → Bristol；遊戲 → Dundee。
4. 蘇格蘭要另算 **所得稅** 與實質到手。

## 七、主張查證（2026-09-05）— Industrial Project／Toptal／路徑取捨

### 主張 1：格大有「企業合作論文／Industrial Project」（5–8 月進企業、雙指導、高機率轉正）
**判定：對「MSc Software Development (Conversion)」過度宣稱／基本不符官方描述（信心：高）**

| 說法 | 官方實際 |

| 與 JP Morgan／Barclays 等合作、進企業做畢業論文 | 課程 Projects 頁：學校**分配**專題或**自提**專題（需學術核准）；例子為 App／遊戲等學術軟體題。**未**寫進企業 5–8 月、企業主管共指導、Return Offer |

### 主張 2：Toptal＋Student Visa 禁自雇
**判定：簽證核心正確；Toptal 平台描述大致合理但薪資為市場傳聞（信心：簽證高／時薪中）**

- Student visa：**禁止** self-employment／business activity（含自由業接案）；少數 Innovator Founder 申請過渡例外。Appendix Student ST 26.5。
- 入境英國持 Student 期間在英接 Toptal／類似平台 → **高度違規風險**。
- 赴英**前**在台灣接案：不在英國 Student 條件管轄內（仍須遵守台灣／客戶端法規與平台條款）。
- 畢業後 **Graduate visa（舊稱常講 PSW）允許自雇**——官方明文可 be self-employed。名稱應用 Graduate visa，非正式法規名「PSW」。
- Toptal「前 3%」、時薪 $60–120+：行銷／市場常見說法，**未**在此輪以官方即時費率表核對。

來源：[GOV.UK Graduate visa](https://www.gov.uk/graduate-visa)、[Appendix Student](https://www.gov.uk/guidance/immigration-rules/immigration-rules-appendix-student)

### 主張 3：Industrial Project vs 自研論文互斥；與找教授／Toptal 關係
**判定：對格大轉型碩士的「二選一戰場」敘事誤導（信心：高）**

- 官方真實選項較接近：**學校題庫分配** vs **自提專題（學術核准）**；多數人走研究組提供的題（GIST／FATA／IDA／GLASS），利於之後 PhD。
- **不是**「被動媒合 JP Morgan 工業論文」vs「拿 KSN 敲門找教授」的官方雙軌。
- 自提＋對準教授研究方向（把既有專案學術化）→ **合理策略**，與官方「可自提」一致。
- Toptal 確實與找教授無關；衝突點在 **Student 禁自雇**，不是課程選題。
- 「極高機率 Return Offer」：本課程頁**無**此保證；屬行銷推論。

**實務結論（給決策用）**  
不要把大學部 SE placement 故事當成轉型碩士標配。若目標是企業經驗：靠徵才、校外實習／工讀（遵守工時與禁自雇）、畢業後 Graduate／Skilled Worker。若有 KSN 級作品：優先評估 **自提 COMPSCI5018P** 對準相關教授，而非等待不存在的保證 Industrial Project 軌道。
